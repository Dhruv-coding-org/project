# 🛡️ CyberZero: From Absolute Zero to Cyber Guardian

Welcome to **CyberZero**! This is an interactive, gamified cybersecurity learning platform designed for **complete beginners** with zero coding or technical background.

We use everyday analogies (like club bouncers, secret locked briefcases, Trojan horse statues, and naive robot guards) to explain how the internet works and how to defend against cyber attacks!

---

## 🌟 How to Play (Two Awesome Ways!)

You can experience CyberZero in two seamless modes. Both modes share the exact same progress file (`profile.json`), so you can earn XP and unlock badges in both!

### Option 1: The Terminal RPG (Interactive Command Line)
Feel like an elite cyber operative in your command line!
```bash
python cyberzero_cli.py
```
* **Commands to try**: `help`, `status`, `modules`, `lesson 1`, `lab 1`, `bot`, `boss 1`.

### Option 2: The Visual Command Center (Streamlit Dashboard)
A sleek, dark-mode visual web dashboard with sliders, charts, clickable phishing emails, and your visual Trophy Room!
```bash
streamlit run cyberzero_app.py
```
* Your default web browser will automatically open to `http://localhost:8501`.

---

## 🤖 Need Help? Summon Cy-Bot!
If you ever feel lost or confused:
* **In CLI Mode**: Type `bot`, `hint`, or `bot ask "<your question>"`.
* **In Visual Dashboard**: Use the **"🤖 Cy-Bot AI Assistant"** sidebar panel or click **"🆘 Cy-Bot I'm Lost! What do I do?"** on any module tab!

## 📚 The 22-Module Curriculum
* **Phase 1: Foundation & The Digital World** (Modules 1–4)
* **Phase 2: Personal Protection & Identity** (Modules 5–8 + **Boss Battle 1: Login Vault**)
* **Phase 3: Digital Contagions & Malware** (Modules 9–12 + **Boss Battle 2: Malware Outbreak**)
* **Phase 4: Web & Network Security** (Modules 13–17 + **Boss Battle 3: Web Siege**)
* **Phase 5: Advanced Defense & Cryptography** (Modules 18–22 + **Final Boss Battle: Global Grid Defense**)

Enjoy your journey from Script Kiddie to Grandmaster Cyber Guardian!
